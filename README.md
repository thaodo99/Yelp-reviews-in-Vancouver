# Yelp reviews in Vancouver

## 📌 Project Overview

This project analyzes Yelp Open Dataset reviews for restaurants in the Greater Vancouver area using Tableau. Interactive dashboards and storyboards were built to explore restaurant distribution, review trends over time, and user behavior patterns, with a focus on changes before and during COVID-19.

## 📌 Objectives
- Visualize the landscape of restaurants in Vancouver by location, rating, and cuisine
- Examine how review ratings and volume evolve over time
- Explore user activity patterns and engagement behavior
- Communicate insights through intuitive dashboards and storyboards

## 📌 Key Components
### Part A — Restaurants Dashboard
- Total number of restaurants in Greater Vancouver
- Top 10 restaurants by review volume
- Interactive map of restaurant locations (downtown-focused)
- Rating distribution that dynamically responds to map filters
- Cuisine-type filtering across major categories

### Part B — Review Dynamics Storyboard
- Distribution of review stars over time
- Temporal shifts in review behavior
- Visual analysis of COVID-19’s impact on review volume and ratings

### Part C — Users Storyboard
- User-level engagement and activity patterns
- Visual exploration of reviewer behavior and contribution trends

## 📌 Tools & Data
- Visualization: Tableau
- Data Source: Yelp Open Dataset (review, business, and user tables)
- Data Format: JSON (preprocessed prior to visualization)
